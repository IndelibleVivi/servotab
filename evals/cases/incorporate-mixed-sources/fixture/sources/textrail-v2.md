# TextRail 2.0 manual snapshot

Synthetic current manual. The compact-view recipe is local: collapse whitespace,
measure the resulting string, and reserve one display unit for an ellipsis when
clipping is necessary. A caller chooses the display unit and whether its own
exports use the compact-view recipe.

This describes an available mechanism. It does not establish that a caller has
installed TextRail, needs it as a dependency, or has consent to upload text.
