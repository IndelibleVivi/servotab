Softpowers is an independent rewrite inspired by:

- Project: `obra/superpowers`
- Author/maintainer: Jesse Vincent / Prime Radiant
- Repository: https://github.com/obra/superpowers
- License: MIT

The original project describes a composable software-development skills methodology including brainstorming, planning, TDD, debugging, code review, worktrees, parallel agents, verification, and branch completion.

This Softpowers pack uses the same general problem domains while independently rewriting the activation model, progressive-disclosure architecture, workflow thresholds, testing policy, subagent policy, review shape, and verification scope. It does not include the original project's mandatory session bootstrap or fixed end-to-end workflow.
